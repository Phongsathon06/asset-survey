# ระบบสำรวจทรัพย์สินและครุภัณฑ์ (Asset Survey Web App)

เชื่อมต่อฐานข้อมูล **Cloud Firestore (`asset-survey-46025`)** เรียบร้อยแล้ว พร้อมสำรองข้อมูลในเครื่อง (LocalStorage) อัตโนมัติ

## คุณสมบัติหลัก
1. **ตารางอิงจาก Excel (`สำรวจ.xlsx`) เป็นหลัก:** คอลัมน์ **ลำดับ**, **รหัสทรัพย์สิน**, **รายการ**, **พบ**, **ไม่พบ**, **สถานที่ตั้ง**, **หมายเหตุ** (ไม่มีแผนก/หน่วยงาน ประเภททรัพย์สิน และผู้ดูแล)
2. **นำเข้าและส่งออกเฉพาะไฟล์ Excel (`.xlsx`, `.xls`):** รองรับการ Import Excel (กรองแถวท้ายฟอร์มอย่าง "ผู้ตรวจนับ..." / "ลงวันที่..." ออกให้อัตโนมัติ) และ Export Excel ตรงตามคอลัมน์
3. **ลบข้อมูลแบบเลือกหลายรายการและลบทั้งหมด:** มี Checkbox เลือกทีละแถว/เลือกทั้งหมด ปุ่ม **ลบที่เลือก (X)** และปุ่ม **ลบทั้งหมด**
4. **กล้องสแกนอ่านข้อความบนสติกเกอร์ (OCR):** กดปุ่ม **สแกน** ข้างช่องค้นหาเพื่อเปิดกล้องอ่านข้อความบนสติกเกอร์แล้วนำไปค้นหาในตารางได้ทันที
5. **ค้นหาและกรองสถานะ:** ค้นหาได้ทั้งลำดับ รหัสทรัพย์สิน รายการ สถานที่ตั้ง และหมายเหตุ พร้อมตัวกรองสถานะการสำรวจ (**พบ**, **ไม่พบ**, **รอตรวจสอบ**)
